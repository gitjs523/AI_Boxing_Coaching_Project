
# 1. 금교혁

# 2. 심규현
```
<AI 복싱 코칭 시스템>

사용자가 카메라 앞에서 복싱 자세를 취하면 관절 움직임을 분석해서 
가드, 잽, 스트레이트, 원투 같은 동작을 인식하는 방식입니다.

단순히 동작을 인식하는 것뿐만 아니라 자세가 올바른지 평가하고, 
잘못된 부분은 피드백해 주면서 훈련 점수도 보여주는 시스템입니다.

Python과 OpenCV, MediaPipe를 활용해서 카메라로 움직임을 인식하고, 
게임처럼 단계별 미션을 수행하면서 다음 단계로 넘어가는 방식.

복싱을 잘 모르는 사람도 게임하듯이 하나씩 배울 수 있고, 
4명이서 기능을 나눠 개발한 뒤 합치면 괜찮은 결과물이 나올 것 같다고 생각했습니다.
```

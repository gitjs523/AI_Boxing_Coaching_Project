# sim-test — 임시 인식 연동 실험
팀원이 전달한 중간 코드의 Letterbox, 관절 신뢰도 기준, 잽/스트레이트/더킹 규칙을 기존 UI와 게임에 연결한 시험용 버전. 양쪽 어깨 및 코가 보이는 것을 요구하며, 이전 관절 좌표는 화면 표시용으로만 사용한다. HSV는 기존 보조 기능이며 팀원의 최종 인식 코드는 포함되지 않는다.

python -m pip install -r requirements.txt
python boxing.py

G 게임, C CLAHE 전환, H HSV, F 필터, P 리포트, R 초기화, S 캡처, Q 종료. 자세 등급은 반대손 가드가 평가된 펀치 5회 및 기본 가드 30프레임 이상 필요. 펀치 가드 70%, 기본 가드 30%의 임시 규칙.

실제 웹캠, 인식률 및 타격 성공은 현장 검증 필요. 기존 sim/main에 병합하지 말 것.

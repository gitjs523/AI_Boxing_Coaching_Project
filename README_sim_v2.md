# AI Boxing Coach | 팀원 3 통합본

기존 sim-v2 프로젝트 최상위 폴더에 압축 파일의 내용을 복사합니다.

```cmd
python -m pip install -r requirements.txt
python boxing.py
```

기존 ONNX 모델은 유지하세요. 모델이 없으면 최초 실행 때 다운로드를 시도합니다. 한국어 UI는 Windows 맑은 고딕 및 Pillow를 사용합니다. 화면은 1440×810 기준으로 구성하고 모니터 크기에 맞춰 축소합니다.

## 조작법
오른쪽 상단 조작법 버튼 또는 `/` 키로 안내를 열고 닫습니다. G: 미트 시작/중지, C: CLAHE 꺼짐/켜짐/자동, H: HSV, F: EMA, P: 보고서 저장, R: 기록 초기화, S: 화면 저장, Q: 최종 보고서 및 종료. 조작법을 열어도 훈련은 계속됩니다.

## 판정 규칙
- 60초 라운드, 미트별 3초, 좌우 번갈아 랜덤 위치, 명중당 10점. 팔 굽힘(110도 이하) 이후 뻗기(145도 이상), 손목 또는 HSV 보조 좌표의 과녁 진입과 어깨 폭 대비 이동속도를 검사합니다. 실패는 시간 초과입니다. 2D 판정으로 실제 타격이나 깊이를 검증할 수는 없습니다.
- 자세 등급: 잽 규칙 충족 및 오른손 가드 성공 비율 70%, 양손 가드 유지 비율 30%. S 90+, A 80+, B 70+, C 70 미만. 최소 잽 5회와 가드 표본 30프레임 미달은 미평가. 실제 복싱 자세 정확도를 검증한 모델이 아닌 팀 내부 참고 지표입니다.
- 게임 통계는 최신 라운드 기준, 자세 통계는 세션 전체 기준입니다. G를 다시 누르면 새 라운드가 시작되고, R은 전체 기록을 초기화합니다.
- Q 또는 P로 reports/ 폴더에 CSV/JSON을 저장합니다. Q는 종료 화면을 표시합니다.
